# ติดตั้งบน Google Sheets และ LINE LIFF

1. เจ้าของระบบสร้าง Google Sheet เปล่า เปิด **ส่วนขยาย → Apps Script** วางเนื้อหา Code.gs ทั้งไฟล์แล้วบันทึก รีโหลดชีต เลือก **ระบบงานสาธิต → ติดตั้ง / ตรวจสอบโครงสร้างชีต** และอนุญาตสิทธิ์ หรือเลือกฟังก์ชัน setupSheets ในตัวแก้ไขแล้วกด Run ใช้บัญชีเจ้าของเดิมในการติดตั้งซ้ำ
2. ระบบผูก SHEET_ID กับชีตนี้ สร้าง Demos, Users, Products, Announcements และสร้างโฟลเดอร์ส่วนตัวสำหรับรูปเมื่อยังไม่มี FOLDER_ID หากมีโฟลเดอร์เดิม ให้ตั้ง FOLDER_ID ก่อนติดตั้ง ระบบคงข้อมูลเดิมและหยุดเมื่อหัวตารางที่มีอยู่ไม่ตรง
3. ใน LINE Developers สร้าง LINE Login channel แล้วเพิ่ม LIFF app เลือกขนาด Full, scope openid และ profile อัปโหลดไฟล์หน้าเว็บที่ราก repository ลง HTTPS เช่น GitHub Pages แล้วตั้ง Endpoint URL เป็น **URL โฟลเดอร์ของแอปที่ลงท้ายด้วย /** เช่น https://example.github.io/sales/ โดยต้องเปิด index.html ได้จาก URL นี้
4. ใน Apps Script → Project Settings → Script properties ตั้ง LINE_CHANNEL_ID เป็นเลข Channel ID ของ LINE Login channel เดียวกัน และ OPENAI_API_KEY สำหรับตรวจภาพ หากต้องการเปลี่ยนโมเดลให้ตั้ง AI_MODEL
5. Deploy → New deployment → Web app → Execute as Me → Who has access: Anyone คัดลอก URL /exec ใส่ใน config.js ช่อง api ใส่ LIFF ID จากหน้า LIFF ในช่อง liffId แล้วอัปโหลดไฟล์ที่แก้ไขขึ้นโฮสต์ หากใช้ deployment เดิม ให้อัปเดตเวอร์ชันที่ Manage deployments
6. เติมรายชื่อสินค้าใน Products และผูก LINE User ID ใน Users กับชื่อ ทีม และบทบาท sales, lead หรือ admin ผู้ที่ยังไม่ลงทะเบียนจะเห็น LINE User ID หลังยืนยันตัวตน ให้ผู้ดูแลยืนยันบุคคลก่อนเพิ่มสิทธิ์ เผยแพร่ LINE Login channel สำหรับพนักงานทั่วไป
7. เปิด https://liff.line.me/{LIFF_ID} จาก LINE หรือใช้เป็นลิงก์ใน Rich Menu พนักงานเห็นงานของตน หัวหน้าและบัญชีเปิดรายละเอียดเพื่อตรวจตามสิทธิ์ของตน หากต้องการลิงก์หลังบ้านโดยเฉพาะใช้ https://liff.line.me/{LIFF_ID}/admin.html สำหรับคอมพิวเตอร์เปิด HTTPS ของ admin.html ได้โดยตรง
8. ทดสอบด้วยลูกค้าสมมติทั้งใน LINE และเบราว์เซอร์ภายนอก ตรวจว่าเข้าสู่ระบบได้ สิทธิ์ข้ามทีมถูกจำกัด ส่งภาพและพิกัดได้ และผลประเมินปรากฏในชีต หากล็อกอินแล้วระบบแจ้งว่าไม่มี ID token ให้ตรวจ scope openid และอนุญาตสิทธิ์ใน LINE

ตัวอย่าง config.js
```js
window.CONFIG = {
  liffId: "ใส่ LIFF ID",
  api: "https://script.google.com/macros/s/ใส่_DEPLOYMENT_ID/exec"
};
```

## ทดสอบหลังเชื่อมบัญชี
ใช้ลูกค้าสมมติ ส่งหนึ่งรายการพร้อมภาพและพิกัด เปิดหน้าวันนี้และทั้งหมด ตรวจว่าเบอร์มีเลขศูนย์นำหน้า ลองด้วยพนักงานอีกคน หัวหน้าทีมเดียวกัน หัวหน้าต่างทีม และบัญชี ตรวจว่ารายการและปุ่มตรงสิทธิ์ ตรวจผล AI หลังรอบประมวลผล
## การใช้งาน
พนักงานเห็นงานของตัวเอง หัวหน้าทีมเห็นและตรวจงานของทีม บัญชีเห็นทุกทีม ทั้งสองฝ่ายบันทึกผลแยกกันครั้งเดียวต่อรายการ พิกัดใช้ GPS ณ จุดที่ยืนหรือกรอกละติจูดและลองจิจูดเอง วันและเวลาใช้ประเทศไทย ID เป็นรหัสรายการ ส่วน LINE User ID ใช้ระบุเจ้าของ รูปในชีตเก็บเป็น Drive file ID และเปิดดูผ่านแอปที่ตรวจสิทธิ์
## AI
เกณฑ์ตั้งต้นให้ผ่านเมื่อภาพแสดงสินค้าสอดคล้องกับชื่อ และมีหลักฐานการนำเสนอหรือทดลองใช้ ปรับคำสั่งใน checkAI ให้ตรงเกณฑ์องค์กร โดยขออนุญาตลูกค้าก่อนบันทึกภาพและพิกัด แจ้งว่ารูปและชื่อสินค้าจะส่งให้ OpenAI เพื่อประเมิน ระบบไม่ส่งช่องชื่อ เบอร์โทร หรือพิกัดให้ AI โดยตรง หาก API ขัดข้องคงสถานะรอตรวจและลองรอบถัดไป ผล AI แยกจากผู้ตรวจทั้งสองฝ่าย
เก็บ Demos ตามลำดับเดิม ใช้ Filter views เมื่อต้องการเรียงดูในชีต หลีกเลี่ยงการแก้ไขแถวโดยตรงระหว่างประมวลผล

## ประชาสัมพันธ์
รัน setup เพื่อสร้างแท็บ Announcements ใส่หัวข้อและรายละเอียดหนึ่งประกาศต่อแถว แอปแสดงประกาศจากแถวล่าสุดก่อน
